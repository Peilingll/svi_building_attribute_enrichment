\chapter{Conclusions}
\label{ch:conclusions}

This thesis examined whether building attributes predicted from \ac{SVI} can support building energy assessment when administrative records are incomplete. The study addressed this question through a Dutch case that applied TABULA-NL as the archetype framework for building stock enrichment. Building type, construction year, and floor count predicted from \ac{SVI} were first compared with reference building attributes. Predicted building type and construction year were subsequently used to assign TABULA-NL archetype cells and representative U-values. All three predicted attributes and the assigned U-values were evaluated as inputs to registered energy class prediction. This evaluation chain traces how errors in building attributes predicted from \ac{SVI} affect archetype assignment, representative thermal properties, and registered energy class prediction.

\section{Conclusions}
\label{sec:conclusions}

For Objective~1, the findings show that \ac{SVI} contains information that supports the prediction of building type, construction year, and floor count. DINOv2 and ResNet-50, both trained with local labels, achieved broadly comparable performance across the three attributes. The DINOv2 configuration produced the most consistent overall results and used fewer trainable parameters than ResNet-50 because its pretrained backbone remained frozen. InternVL3-2B with prompting and without parameter updating produced the weakest results for all three attributes. The consistent performance of DINOv2, particularly for less frequent building types, supports its use for enriching missing building attributes from \ac{SVI} when labelled development data are limited.

For Objective~2, the findings show that errors in predicted building type and construction year affect both TABULA-NL archetype assignment and the associated thermal properties. DINOv2 and ResNet-50 achieved joint archetype cell accuracies above 80\%, but low macro cell recall showed that this performance did not extend to less frequent cells in the evaluation set, which was dominated by older apartment blocks. Across the three vision configurations, calculations based on predicted archetype cells produced aggregate $h_{tr}$ values from 9.8\% to 16.6\% higher than the reference cell calculations. Construction year errors tended to assign newer buildings to earlier TABULA-NL periods with higher representative U-values, increasing the calculated $h_{tr}$. The results indicate a tendency for newer buildings to be assigned to earlier TABULA-NL periods. Because these periods have higher representative U-values, the assignments increased the calculated $h_{tr}$.

For Objective~3, the findings show that \ac{SVI} can support registered energy class prediction through predicted building attributes and direct image prediction. Replacing reference attributes with attributes predicted by DINOv2 reduced binary macro F1 by 0.002, showing that the predicted attributes retained most of the performance available from reference attributes. For the binary target, the direct image and predicted attribute conditions based on DINOv2 and ResNet-50 performed above the uniform random expectation. Direct image prediction with DINOv2 achieved the highest macro F1 for both energy class targets. For the target with seven classes, the difference between exact and $\pm1$ accuracy indicates that predictions often remained close to the registered class, but adjacent classes were not distinguished reliably. Among the structured inputs, construction year made the largest marginal contribution to energy class prediction and should therefore be prioritised when improving building attribute prediction from \ac{SVI}.

Overall, the findings support \ac{SVI} as a supplementary source of building attributes when reference building attributes are incomplete. When explicit building attributes are required, predictions of building type, construction year, and floor count provide inspectable inputs for preliminary building stock assessment. Predicted building type and construction year can subsequently support TABULA-NL archetype assignment. When registered energy class prediction is the only required output, direct image prediction with DINOv2 achieved higher macro F1 than both attribute conditions for the binary target and the target with seven classes. Attribute prediction and direct image prediction provide screening information, while \ac{EPC} certification, physical surveys, and measured performance assessments remain necessary when certified or measured evidence is required. The appropriate use of \ac{SVI} therefore depends on whether the application requires inspectable building attributes, representative U-values for archetype analysis, or direct registered energy class prediction.

\section{Contributions}
\label{sec:contributions}

This thesis made three contributions to the evaluation of building attributes predicted from \ac{SVI} for building stock enrichment.
These contributions concern the controlled assessment of attribute sources and their consequences for archetype assignment and energy class prediction rather than the development of a new predictive architecture.

\textbf{The first contribution is a controlled evaluation of building attribute prediction from SVI.}
The comparison evaluates ResNet-50 with full fine tuning, DINOv2 with a frozen backbone and trained prediction heads, and InternVL3-2B without parameter updating. All three vision configurations predict the same three building attributes and are assessed on the same 2,014-building evaluation set. This common evaluation protocol shows how performance varies across building type, construction year, and floor count and supports a consistent comparison of the three configurations.

\textbf{The second contribution evaluates the effects of building attribute prediction errors through archetype assignment and thermal calculation.}
At the building level, the experimental dataset links Mapillary imagery, reference building attributes, reconstructed 3DBAG geometry, EP-Online certificate records, and TABULA-NL archetypes while recording the source of each field. Using these links, reference and predicted attributes can be compared for the same building. Predicted building type and construction year determine the predicted archetype cell, which supplies representative U-values. Combined with reconstructed 3DBAG geometry, these values are used to calculate the transmission heat transfer coefficient normalised by floor area, $h_{tr}$. Comparison with the reference cell calculation quantifies how building attribute prediction errors change archetype cell agreement, representative U-values, and $h_{tr}$.

\textbf{The third contribution compares three conditions for registered energy class prediction.}
The reference attribute and predicted attribute conditions use the same fitted LightGBM classifier and are evaluated on the same 2,014-building evaluation set. This design shows how performance changes when reference building attributes and their representative U-values are replaced with predicted building attributes and the corresponding U-values. Evaluated on the same buildings, the direct image condition predicts the registered energy class directly from SVI without intermediate building attributes. Separately, feature ablation on the development set identifies the marginal contribution ofstructured inputs to the reference attribute classifier.
